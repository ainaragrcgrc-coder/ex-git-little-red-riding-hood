# Caperucita Roja

## Descripción

Este proyecto consiste en crear una página web para contar la historia clásica de Caperucita Roja utilizando HTML5 y CSS3.

El objetivo principal del ejercicio es practicar Git y GitHub, especialmente la realización de commits atómicos, descriptivos y organizados.

## Planificación y prototipado

Antes de comenzar el desarrollo, se realizó un prototipo inicial utilizando Stitch para definir la estructura visual de la página.

La propuesta se organizó en una portada y cinco capítulos:

1. Caperucita Roja
2. El bosque
3. El lobo
4. La casa de la abuela
5. El rescate

El diseño busca transmitir una estética de cuento clásico mediante colores cálidos, una tipografía sencilla y una estructura clara. También se tuvo en cuenta que la página pueda adaptarse a diferentes tamaños de pantalla.

## Planificación de commits

Para mantener un historial de Git organizado se decidió dividir el desarrollo en tareas pequeñas y realizar un commit después de completar cada tarea lógica.

Se utiliza la convención Conventional Commits:

- `feat:` para nuevas funcionalidades o contenido.
- `style:` para cambios visuales y de diseño.
- `fix:` para correcciones de errores.
- `docs:` para documentación.

Ejemplos de commits planificados:

- `feat: add basic html structure`
- `feat: add chapter 1 little red riding hood`
- `feat: add chapter 2 the forest`
- `feat: add chapter 3 the wolf`
- `feat: add chapter 4 grandmas house`
- `feat: add chapter 5 the rescue`
- `style: add story layout and typography`
- `feat: add story images`
- `style: add responsive design`
- `fix: correct image paths`
- `docs: add final screenshot and deployment link`
